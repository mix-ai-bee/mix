Windows всё включено

Настоящая программа: управляет компьютером, видит экран, маленький Mix-маскот, голоса Microsoft. Python не нужен.

  1. Скачай Mix.exe.
  2. Открой его — Mix сам предложит установиться: ярлык на рабочем столе и в «Пуске».
  3. Удалить можно в «Параметры → Приложения».
⬇ Скачать Mix.exe Windows 10/11
Windows может предупредить. У Mix пока нет платной цифровой подписи, поэтому появится «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае». Если включён Smart App Control, Windows не даст запустить файл — тогда поставь Mix через браузер (карточка ниже).
🤖

Android APK

Обычное приложение для телефона: голос, Live, камера, диктовка, файлы, монтаж роликов. Работает и без интернета (кроме самих ответов ИИ).

  1. Скачай Mix.apk.
  2. Открой файл. Телефон спросит, можно ли ставить приложения из браузера, — разреши.
  3. Нажми «Установить».
⬇ Скачать Mix.apk Android 7+
Это безопасно. Предупреждение «приложение из неизвестного источника» появляется у всех приложений не из Google Play. Mix не просит ничего лишнего: только микрофон и камеру, когда ты сам ими пользуешься.

Через браузер без файлов

Mix ставится из Chrome или Edge как приложение: своя иконка, своё окно, без адресной строки. Подходит для Mac, Linux, Chromebook, а также для Windows и Android, если файлы ставить не хочется.

  1. Нажми кнопку ниже.
  2. Подтверди «Установить».

iPhone и iPad

Своя иконка на экране, Mix открывается на весь экран, как приложение. Ставится за 10 секунд прямо из Safari.

  1. Открой этот сайт в Safari.
  2. Нажми «Поделиться» ⬆︎ внизу экрана.
  3. Выбери «На экран Домой» → «Добавить».
▶ Открыть Mix в Safari
Почему не файлом? Apple разрешает ставить приложения файлом только через App Store, а это 99 $ в год. Поэтому на iPhone Mix ставится с сайта — получается то же самое приложение со своей иконкой.

На телефонах и в браузере нет того, что связано с управлением компьютером (мышь, маскот, голоса Microsoft). Всё остальное — как в программе. Чаты везде хранятся только на твоём устройстве.
